# Session-Manager-GUI

DeepSeek Harness（web profile）双半面插件（独立插件，当前版本 **0.1.6**）。

- **主机半面**（`lib/index.js`）：“会话回收站”数据层 + 已归档会话数据 +
  同源 JSON API（前缀 `/Session-Manager-GUI`，供浏览器半面调用）。
- **浏览器半面**（`lib/client.js`）：手写 `__ModuleLoader__` 产物，零构建；
  向设置页注册三个区块（“会话回收站” order 30、“已归档会话” order 31、
  “常规不可见会话” order 32），并监听会话行菜单补丁派发的
  `Session-Manager-GUI:delete` 事件。

## 界面变化

- 会话行右侧三点菜单新增第 4 项 **删除会话**，带与“会话回收站”一致的
  垃圾桶图标（`IconTrashOutline16`）；
- 设置导航新增 **会话回收站**（垃圾桶图标）、**已归档会话**（归档图标）与
  **常规不可见会话**（自绘 eye-off 图标），不再使用默认齿轮图标；
- 会话回收站里，**子代理会话**的条目标题前带一个「子代理」标志（内置层级图标），
  悬浮可看所属父会话 id。

## 0.1.6 要点

- **父子绑定**：删除父会话时连带其子代理会话（多级派生）一并移入回收站，恢复时一并恢复；
  派生的 fork **不会**被级联；
- **常规不可见会话页**：统一管理平时侧栏看不到的会话（子代理 / 空白 / 无归属），
  支持按组批量彻底删除；
- **路径白名单守卫**：所有文件操作限定在 `$DSH_HOME` 内的会话数据范围，且用 realpath
  阻断符号链接逃逸——**绝不删除或写入工作区文件**；
- **僵尸 Agent 修复**：删除会话时成对退役代理注册项，避免后续消息进队列却永不落盘；
- 修复“删除当前打开的会话 → 恢复后该标签页显示会话不可用”（现在恢复后立即可用，无需刷新）；
- 修复“原工作区目录已不存在时会话无法恢复”（现在照常恢复日志，落到“未分类”）。

完整变更见上一级《开发日志.md》§21；使用说明见《使用手册.md》。

## 与 session-editor 的关系

两者是**不同的插件**：聊天工具（`session_editor_list` / `session_editor_restore`
/ `session_editor_delete`）由 `session-editor` 提供；本插件**不注册这些工具**，
因此可同时安装、互不冲突。WebUI 的“删除会话”是软删除（进回收站），
聊天工具的删除仍是永久删除。
